# Images Folder

Use this folder for future bot images, banners, cards, and embeds.

Recommended naming:

- `feature-context-version.ext`
- Keep names lowercase.
- Use hyphens instead of spaces.
- Prefer stable, descriptive names over timestamps.

Examples:

- `shop-ministry-v1.png`
- `profile-card-v2.png`
- `route-combat-banner-v1.jpg`
- `hunting-forest-card-v1.webp`

Suggested subfolders when assets grow:

- `images/shop/`
- `images/profile/`
- `images/routes/`
- `images/hunting/`
